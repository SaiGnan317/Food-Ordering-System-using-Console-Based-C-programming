# Food-Ordering-System-using-Console-Based-C-programming
A C-based Food Ordering System that manages menu items, sorts them by price using insertion sort, accepts customer orders, stores them using a deque, and generates an order summary and final bill with quantity and total price

### Features

* Displays food menu with prices
* Sorts menu using insertion sort
* Accepts food item and quantity
* Stores orders using a deque
* Displays order summary
* Calculates and displays the total bill
* Handles invalid item IDs and quantities

### Concepts Used

C Structures, Arrays, Deque, Functions, Insertion Sort, Loops, Conditional Statements, and String Handling.
